# Wrath of the Aztecs

A platformer game where you have 30 seconds to reach your house in order to save yourself from a flood, this game was made for GMTK 2026

You can play it at https://imran143307.itch.io/wrath-of-the-aztecs

This game was made in Pygame, and the music made in Bosca Ceoil

All of the game's code and assets are on the 'master' branch

Feel free to contribute to the code by creating a new branch or forking the repo
